## 结论：不直接使用

| 项目 | 原件 | 游戏需要 |
| --- | --- | --- |
| 三角面 | 每个 50 万 | 敌人约 1 万，第一人称枪约 6000 |
| 网格 | 1 个整体网格，2200 到 3100 个碎块，6.6 万到 7.9 万条非流形边 | 按部件分开的封闭块体 |
| 材质 | 1 张 4096 贴图 | 项目色板材质，快攻敌人要整体换色 |
| 骨骼与枢轴 | 无 | `LeftArm` 等节点在肩、髋处转动 |
| 朝向与尺寸 | 敌人面朝 +Z、高 1.09 米；两把枪枪口朝上 | 面朝 -Z，头部中心 1.70 米，照门坐标固定 |

修复所需的减面、拆件、重做枢轴和换色，工作量超过照四视图程序化重建，而这三件本来就是方块造型。原件只用来量比例：腿长约占身高的 57%，肩线约在 70%，头宽约为肩宽的 27%。

成品由 `tools/build_toy_actors.py` 生成。下载时步枪手和玩家步枪的文件放反了目录，这里已按内容重新命名。
