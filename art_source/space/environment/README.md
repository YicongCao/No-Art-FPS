# 月球全图环境生产源

运行 `build_environment.py`（Blender Python）可重新生成本目录全部 `.blend` 及 `assets/models/space` 中的对应 GLB。随机噪声使用固定种子；没有在线生成依赖，也没有新增 Tripo 消费。

资产包括：连续月面山脊、服务站、横置氧气储罐、模块化围墙、太阳能阵列、停机灯、货箱，以及电池架、阀门组、控制台、补给箱四类可破坏装置。Blender 采用 Z 向上、+Y 正面，导出 Godot 后为 Y 向上、-Z 正面。服务站保持 5 × 4 米碰撞包络，室内关闭；天线和散热器在屋顶。

复杂物体使用倒角盒体、挤出轮廓、圆柱管道、法兰、支架和重复模块组装。静态部件按材质合并，`TargetN` 与 `RemnantN` 保持独立，目标的屏幕/指示灯作为子节点随破坏隐藏。游戏加载 GLB，不在战斗中生成几何或噪声纹理。

山体由固定种子的分形噪声和环形山脊生成，边界外延至 220 × 220 米。纹理采用制作端烘焙的频谱噪声，避免规则正弦纹理形成条带。山体仅为边界外视觉；实际游玩地面与边界碰撞保持原布局。远景行星在地图生成器中使用球面噪声烘焙，是风格化天体，不是准确的地球地图。

`asset-stats.json` 记录当前导出三角形与网格。源码保留单件结构；未做本轮之外的统一 LOD、贴图裁剪或复杂图集合并。
