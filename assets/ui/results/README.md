# Results icons

Generated with the built-in **imagegen** tool on 2026-11-06. The four original 1254 × 1254 RGBA PNGs are preserved unchanged, with real alpha transparency. Godot generates mipmaps for small-size display. No external icon set or CLI fallback was used.

- `retry.png`: retry the round.
- `home.png`: return to the title.
- `kills.png`: current round's kills.
- `trophy.png`: saved highest score; a gold ring indicates a new record.

The live layout, button backgrounds, hover/focus states and score numbers are drawn by `scripts/hud.gd`. Button faces have no text; their tooltips explain the action and keyboard shortcut.
