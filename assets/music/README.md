# No-Art-FPS score

- `sixty.mid` and `sixty.ogg` contain the 45-second, 160 BPM combat cue.
- `destroy.mid` and `destroy.ogg` contain the 15-second, 192 BPM DESTROY ALL cue.

The MIDI files contain editable bass, brass, drone and percussion tracks. The Ogg files render the same notes with original oscillator and noise synthesis. Run `blender --background --python tools/build_music.py` with ffmpeg on PATH to regenerate both.
