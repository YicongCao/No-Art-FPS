# 雨市共享材质细节

`surface_noise.png` 由 `godot --headless --path . --script tools/build_market_surface.gd` 确定性生成（seed 11011，512 x 512 无缝噪声）。启用 mipmap，供涂装、金属、混凝土、棚布与水洼共用，不含第三方纹理。

`scripts/maps/market_lookdev.gd` 仅为雨市实例分配材质覆盖，不改导入 GLB 的共享材质。四类表面使用不同粗糙度、低强度法线扰动和纹理尺度。固定灯具的低强度局部漫反射补光是解析近似，实际光源、狂暴灯与动态阴影仍由引擎处理。

主通道反射沿原地图斜面计算；侧巷和非共面地面保留程序近似。反射层排除地面、玩家武器、敌人、雨和屏幕效果，避免递归与不必要的绘制；不是完整光追反射。结构/道具隐藏后不会继续画进实时镜像。静态环境探针不用于精确描述可破坏物。
