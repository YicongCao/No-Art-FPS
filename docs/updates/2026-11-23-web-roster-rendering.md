# Web：九张计分地图的静态物件合批

把 [BB 办公室的 Web 合批](2026-11-23-web-office-rendering.md)推广到九张正式计分地图。不改变原生版、隐藏的 Dust 拆弹任务、画质设置或运行时依赖。

Web 在地图材质和反射层设置完毕后，把同一空间单元内使用相同网格、材质和绘制设置的重复物件提交为 `MultiMesh`。碰撞体、导航和破坏逻辑仍归原物件所有：单件破坏只隐藏自己的实例，重开恢复。透明材质、活动设施、独立交互物件和可打通通路的结构不进入这批优化。沙城的大部分建筑原本已合并，本次只合批重复云朵；它们不参与终场清场。
