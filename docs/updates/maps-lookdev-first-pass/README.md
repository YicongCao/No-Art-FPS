# 其余 11 张地图：首轮材质与光色改造

本轮按“先覆盖，再打磨”实施。保留布局、碰撞、导航、武器与规则，雨市沿用已发布的专用方案。其余地图采用独立配置的首轮材质和灯光方向，不宣称已达到逐图概念设计质量。

## 从雨市沉淀的流程

1. 先查看实机和原始材质，明确灯、地面、天空各自的职责；用同机位图判断改善，不能拿概念图当验收结果。
2. 先做明暗层次与冷暖关系，再调粗糙度、反光和细节。环境补光太强会使画面发灰；高光弱时堆噪声只会显脏。
3. 材质在地图实例上覆盖，保留原 GLB、透明材质、专用 shader 和已有纹理。地图切换后不污染其他场景。
4. 湿面反射必须有遮罩、视角变化与灯具位置依据。雨市主坡镜像不能直接复制到多楼层、台阶或非共面地图。
5. Web 实际运行后才能决定反射方案。雨市的环境探针曾触发 WebGL 深度 blit 错误，因此 Web 禁用探针；本轮不新增探针和镜像视口。
6. 原生计时、浏览器 RAF 和人工试玩分开报告。检查启动、射击、狂暴、重开、切图；逐图保存实际截图。
7. 提交并推送代码，从 origin/main 导出，发布双站，校验资源和线上启动，保留旧发布用于回滚。

## 首轮覆盖

| 地图 | 光色方向 |
|---|---|
| 默认训练场 | 暖日照、冷阴影，保留清楚的靶场辨识度 |
| 游乐园 | 暖主光与偏紫环境，增强发光设施 |
| 末班渡轮 | 暖码头灯、冷海港环境 |
| 夜间摄影棚 | 暖实用灯、冷环境，保留舞台灯控制 |
| 沙门 | 暖砂石、偏冷阴影，避免整体泛黄 |
| 办公室 | 中性冷环境、微暖灯具 |
| 魔法城堡 | 暖石墙与冷阴影，强化发光材质 |
| 行李层 | 冷工业环境、暖灯具与设备高光 |
| 雪线 | 冷雪地、暖设施，避免将雪调成湿路面 |
| 棕榈屋 | 暖日照、青色环境与植被色彩 |
| 银座站 | 冷站厅、微暖灯具，保留警示灯时序 |

实现：共享噪声重映射至 0.65–1.0，避免干燥地面变成过亮镜面；生成入口为 `tools/build_dry_roughness.gd`。它只用于无既有贴图的实体材质粗糙度；适度提高原材质色彩饱和度，逐图调整光色、环境亮度和发光强度。保留动画控制器对狂暴灯光的覆盖。本轮没有增加几何细节、逐灯烘焙或新增湿地镜像，后续逐图按实机反馈精修。

## 验证

`tools/maps/check_all_lookdev.gd` 逐图检查材质实例化、导航、60 秒规则、8 个敌人、狂暴和重开，并保存出生视角实机截图。截图不是无敌人环境宣传图。

11 张地图原生检查与 Web 开局射击冒烟检查通过，无脚本或 WebGL 错误。Web 每图仅采样 2 秒，不能作为性能验收；调整干材质粗糙度后另对游乐园、办公室、雪线复测。规则测试通过。

新增踩坑：批量验收必须先回到 TITLE 并断言实际 map_id，否则选图被运行状态拦截会产生假通过；生成材质需随地图保留引用，并在节点入树后应用，避免 Compatibility 延迟渲染队列引用已释放材质。
