# 主分支远程敌人命中率移植

从 toy 的 `a1082fb4c91db2dd0608f3f270667f89fb42ab4e` 移植到 main，提交 `2c1d066777fc53351f14ab41c47b9f79e0fe351b`。仅包含敌人/游戏逻辑、命中率测试、感知测试的固定命中配置与测试入口说明；排除了原提交夹带的 toy 工具 UID。没有移植 toy 模型、材质或渲染。

远程敌人每发有 30% 概率朝玩家原瞄准点射击，其余弹道向侧面偏移，保留可见曳光与近失音效。这是瞄准概率，移动和掩体仍会影响最终受伤概率。

## 自动验证

- Godot 4.7.2 导入和规则检查通过。
- 原生实际渲染：4000 发样本中瞄准比例 29.9%，所有 2805 发故意打偏样本均清空玩家碰撞体且经过近失范围；可见弹道、掠过音效、不扣血与命中扣血检查通过。
- 感知回归：探测距离、瞄准时间、背后预警、暂停、掩体碰撞、近失与重开清理检查通过。
- Headless 命中率断言通过（30.9%），退出时仍有 4 个资源引用清理日志；严格 qa_run 包装因此返回失败。随后直接运行原生渲染与感知测试通过，没有将退出清理日志称为玩法断言失败或已解决内存问题。
- 本地 Web 10 秒射击/换弹检查通过，未捕获脚本或 WebGL 错误。未进行人工手感验收。

原生截图和完整测试输出保留在独立工作目录的 artifacts/local 与 /tmp/accuracy-*.log。
