# 渲染与狂暴切换优化

2026-11-11。基于上一轮 Apple M5 / Godot 4.7.2 Compatibility 数据定位，本轮保留场景颜色、材质和布局。

## 修改

- 原生太阳阴影由双级联改为单次正交投影，距离 65m 改为 45m；减少重复阴影提交。代价是远处阴影覆盖缩短、近处阴影精细度可能变化。Web 原有预算设置继续生效。
- 同一源材质在地图内共享替换资源，只为摄影棚帘幕、游乐场灯泡等真正不同的语义保留变体，减少资源与切换时 uniform 更新。
- 渡轮镜像保持 640px 宽，更新频率限制 30Hz，主画面正常刷新。镜像运动的时间分辨率相应降低。
- 车站可见性仅在模式切换时更新；行李层落光强度没有变化时不重复上传参数。
- 加载遮罩后预提交狂暴灯光与光束组合，镜头旋转四方向；原生特效由地板下预热改为镜头内提交，包含火焰弹、碎片和爆炸材质。不能保证驱动之后所有位置、光源组合都完全无编译。
- 在加载阶段预生成狂暴提示字形及描边，覆盖桌面和触屏字号。API 依据 [Godot FontFile 文档](https://docs.godotengine.org/en/latest/classes/class_fontfile.html#class-fontfile-method-render-range)。
- 浏览器测试新增 NO_SAMPLE_SCREENSHOT，性能采样中关闭狂暴截图，保留采样前后截图。

## 验证

规则与颜色材质断言通过；11 图实机正常/狂暴/重开渲染检查通过。render/ 保存蓝天、纯色、海报、灯光等回归截图。本轮为自动化验证，没有人工手感验收。

## 切换采样的限制

before-transition.json / after-transition.json 将规则时钟直接设置到狂暴起点，随后记录 3 秒。该路线会同时使敌人数量目标和巡逻时钟跃迁，不能只归因于模式灯光切换。最终 after-transition 在导出和浏览器都结束后串行采集。原生最大长帧仍存在；尚未证明消除原生切换尖峰。

Web 对比采用完整 60 秒自然推进、持续射击与换弹；采样期间不截图。before 是线上未优化版（相同渲染策略，提示文案版本可能有差异），after 是本地最终版；加载速度不作对比。窗口使用采样起点后的 42–49 秒，约覆盖 45 秒狂暴切换；RAF 是浏览器调度间隔，不是 GPU timer。

这是每版一个回合的观察值，不能视为所有地图/设备的稳定收益保证。原生仍有较长单帧，需要继续用 CPU/GPU profiler 分离驱动编译、AI 与特效创建成本。
