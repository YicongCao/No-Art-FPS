共用层采用地图独立材质实例、世界尺度材质细节、按地图配置的描边、简化 SSAO 与低强度 Glow。室内灯下受光由裁切网格表达，少量真实灯补充动态物体照明；不是全场烘焙 GI。地面采样先寻找受光表面，再检查到灯的可见性，拒绝垂直墙面及跨高度三角形。普通顶灯关闭时同步关闭对应落光。

渡轮使用独立 640 像素宽反射视口，只捕获地图环境，不含武器、敌人、海面自身和新增透明落光。实时捕获与原有水波颜色叠加；目前不对倒影做法线折射扭曲。其他干燥地图不套用雨市水面。

游乐场实验性贴图、专用 shader、生成脚本、预览工具、解锁快捷键、右键/长按菜单和爆炸桶兼容逻辑已经移除；旧设计图仅保留为历史资料，不进入游戏导出。

## 实机检查中修正的问题

- 只调整 StandardMaterial 表面会漏掉 material_override 的原始材质；现在同时处理两种来源，保留原有专用 shader。
- 普通顶灯只有发光外观不能形成落光。补充局部受光区，同时压低均匀环境补光。
- 原先地面长条叠加过亮；改为低强度、视角相关的宽高光，避免车站像铺着白色灯板。
- 雪面不能单靠粗糙度避免过曝，同时降低雪面反照率和太阳能量。
- 反射相机能生成画面不等于倒影正确。用单独捕获图和海面重点机位检查水平轴映射；当前 GLES 路径使用经过实机确认的直接采样，暂不叠加 UV 扭曲。
- 狂热与重开会重写环境参数；地图组件在状态切换后重新应用，避免只乘一次系数。
- 游乐场 gold_light 同时用于灯泡、铜杆和地板；按实际构件分别处理，不能全场当作发光材质。

## 验证范围

- Godot 导入、规则测试、11 图 headless 检查、原生渲染正常／狂热／重开、地图选择及导航失败回退检查通过。
- 雨市独立材质、反射与切图释放回归检查通过。
- 原生每图保留出生、左右视角及狂热截图，另补木马、温室内部、渡轮海面重点机位；不是人工手柄完整游玩验收。
- 11 图均通过本地 Chrome/WebGL2 开局、射击与换弹冒烟检查，每图采样 3 秒，无脚本或 WebGL 错误；这不是性能验收或完整回合验收。线上发布结果见后续记录。

## 明确留到下一轮

按用户要求，本轮没有进行性能优化，也不宣称 60 FPS、手机达标或长时间稳定性达标。新增 SSAO、落光网格及逐帧海面反射需要单独量测成本，再决定合批、更新频率、距离裁剪和画质分档。

本轮使用简化 SSAO 而非逐资产离线 AO 烘焙；静态材质高光不是逐区域离线环境反射贴图。温室屋架地面纹理是局部近似并随狂热关闭，并非精确烘焙太阳投影；原有真实阴影仍保留。光束是网格模拟，并非真正的体积雾。受光网格生成时依据场景静态碰撞，动态物体依靠真实灯照明；破坏后局部受光遮挡的完全重建尚未实现。
