# SVG 图标与全屏提示修正

2026-11-06。

- 项目 AGENTS.md 记录用户偏好：工程中不用 emoji／图形字形充当图标，需要时绘制 SVG。长期偏好另按用户要求记录在本地 memory 更新目录，不放进公共仓库。
- Web 加载页的外链、全屏，以及开火、跳跃、换弹、暂停控件统一自绘 SVG，保留 aria-label。SVG 子元素不拦截指针，按住反馈绑定到按钮。
- 删除“添加到主屏幕”的运行时提示。自动全屏失败保持安静；手动点击全屏失败只在菜单中提示“此浏览器暂不支持全屏”，2.4 秒消失。
- 状态变为 LOADING／RUNNING 时立即清除提示和计时器，并用请求序号丢弃迟到的失败结果；CSS 再限制游戏中不得显示。成功重试也清除旧提示。
- 自动化检查覆盖 SVG 子元素事件、自动失败、手动提示时限、状态切换、延后拒绝、再次成功及原有多指输入边界；Web 导出与资源清单检查通过。

陀螺仪本轮只研究：[可行性与接入建议](../design/2026-11-06-gyro-aim-feasibility.md)。未加入传感器权限请求或采集逻辑。
