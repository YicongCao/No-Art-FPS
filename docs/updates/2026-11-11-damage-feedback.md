# 受击方向与死亡回看

玩家经常不知道被哪个方向的敌人打死。本次补齐四类提示，全部不显示血量，不加文字。

- **死亡回看**：死亡后 0.6 秒内视角转向凶手，停在复活骷髅上方。凶手加金色描边，被遮挡时透过墙体显示轮廓，头顶有金色三角。被爆炸炸死时视角转向爆点，那里扩散一圈冲击波。减少动态效果时直接切到凶手。复活时清除描边。
- **准星受击环**：每个攻击者一条弧，最多同时三条，各自在 1.4 秒内淡出。弧随转身实时指向攻击者，伤害越大越长越粗。子弹为红色，爆炸为橙色双弧。画面内的攻击者头顶闪红色三角。原先只在画面外显示的边缘受击标记由此取代。
- **方向音效**：受击时在攻击者方向 1.6 m 处播放 3D 冲击声，背后中弹音调更低更响。子弹从 1.3 m 内擦过时播放掠过声。
- **开火预兆**：敌人瞄准蓄力时枪口出现逐渐变亮的闪光，瞄准线由浅灰逐渐变为暗红。画面外侧方正在瞄准的敌人，最多两个在屏幕边缘提示，背后预警保持原有规则。

自动检查：`python3 tools/qa_run.py -- --qa --damage-feedback`。实际手感、环与提示的显眼程度需人工试玩确认。
