# 旧地图场景化

旧场地现在从 `scenes/maps/yard.tscn` 加载，布局不再由运行时 `build()` 创建。建筑视觉和碰撞归属各建筑父节点，开局、增援、巡逻、玩家起点及复活位置保存为 Marker3D。共享纯色和场地涂鸦材质位于 `assets/materials/`。重复结构仍由保存的 MultiMesh 绘制。

一次性转换工具是 `tools/maps/save_yard.gd`，旧建造配方保存在 `tools/maps/build_yard.gd`，不进入游戏运行链。转换工具会覆盖作者场景，日常编辑直接打开 `.tscn`；不要在手工调整后重新生成。旧模型在转换场景中保存为静态几何，`.blend` 和 GLB 素材来源继续保留；新地图将按可编辑建筑分组导出。

规则/会话资源已独立。旧场地保留原 60 秒计分、复活、45 秒 DESTROY 和最后一秒全场引爆。拆弹规则的独立检查覆盖三个唯一目标、取消、死亡优先、截止和重开，尚未接入任务地图。

Godot 4.7.2 导入、旧计分与拆弹规则测试通过。保存后重新加载的场景通过真实渲染交互、双向楼梯路线、头身命中、遮挡、重开、终局引爆和逐像素定格测试；无窗口建筑坍塌/导航恢复也通过。以上为自动检查，不是人工试玩。
