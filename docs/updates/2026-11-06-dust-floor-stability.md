# 行走时地板闪烁修复

B 点与中路的奶油色连接地板，与相邻沙色地面处于相同高度 -3.5 m，重叠面积分别约 96 和 32 平方米。两张表面同时争抢深度，移动视角时颜色跳变。现将 B 点地面分为两个相邻地块，中路地面缩至连接地板边缘，保留完整地面覆盖，几何、碰撞和导航均重新保存。

没有用提高绘制优先级或偏移整个地面掩盖问题。Blender 建造脚本增加同高度水平地板不得面积重叠的断言，重建地图会自动检查。`.blend`、GLB 与 `.tscn` 已同步。

修复前后各对两个固定地面点使用 36 个实际渲染帧，镜头在附近移动，采样 5×5 像素平均颜色；每次采样射线确认没有墙体遮挡。最大 RGB 欧氏色差从约 0.394885 / 0.253929 降至 0.002667 / 0.000000。该检查用固定世界点排除画面本身随走动变化的影响，不将整幅画面的像素变化错误地视为闪烁。日志与诊断截图保留在 Git 忽略的 `artifacts/local/`。

运行 `--mission --qa --floor-render` 检查移动视角下的稳定性。Godot 导入、实际环线行走、三个目标流程、地面覆盖/跌落冻结与计分规则分别用于回归；以上为引擎自动验证，不是人工试玩。此前扩展地图、雷达和拆除圆环见 [地图修订](2026-11-06-dust-map-revision.md)。
