# 色彩、场景细节与性能基线

2026-11-11。根据用户对上一版 v8 的逐图反馈修正，保留原有布局、碰撞和玩法。本轮采集性能数据，不进行完整性能优化。

[实机修正前后对照](comparison.html)

## 修正内容

- 训练场：恢复原来的 `#5b7fc8` 蓝天。实机逐项关闭对照确认，全屏 Glow 是天空泛白的触发因素；背景色本身未被修改。停用新增共用层的 Glow，雨市专用系统保留。
- 游乐场、渡轮、沙门、城堡等：纯色漆面保留源 StandardMaterial3D 及原色，不再一律改成带噪声的通用材质。普通状态恢复作者原来的环境光色。天然石材、木材等仍保留较轻的材质细节。
- 渡轮：减少基础日照、探照灯放大量和甲板落光强度，保留海面反射与冷暖关系。
- 摄影棚：新增可见的顶部柔光灯箱和固定宽角主光。主光照亮舞台人物与布景，原有移动聚光灯继续形成动感。
- 办公室：新增四张不同的原创像素插画，分别为天空信使、竞技守卫、海滨赛车、遗迹探索；不使用现有游戏角色、标识或名称。每张只使用一次，挂在不同的实心墙段，画面比例为 9:16。
- 城堡球场：恢复原材质的双面显示。球环原来是薄片几何，上一版替换 shader 时丢掉双面渲染状态，因此从一侧看不到；本轮按源材质保留背面剔除设置。
- 温室：白色骨架恢复白漆，不再按裸金属处理；同时检查其他地图的纯色表面，取消统一噪声与错误金属化。

## 回归保护

`tests/color_material_check.gd` 检查训练场天空与重开恢复、双面 shader、温室白漆颜色与金属度、摄影棚主灯，以及四张海报的独立贴图和 9:16 比例。`tools/maps/check_all_lookdev.gd` 支持独立输出目录，保留上一版截图；新增球环、主灯和海报重点机位。

## 性能采样方法

原生：Apple M5，Godot 4.7.2 Compatibility，固定游戏窗口。玩家站立，镜头缓慢左右扫动，敌人 AI 与战斗逻辑继续运行。每图预热 60 帧，再采集普通阶段 15 秒；另采集重点地图的狂热阶段。记录帧间隔 P50/P95/P99、draw calls、对象与图元数量、引擎纹理/静态内存计数。

Web：使用本机硬件 Chrome/WebGL2、1280 × 720，独立运行浏览器测试，避免与原生渲染并发。记录 RAF 间隔和加载耗时，采样中持续射击和换弹。

帧间隔包含调度与 VSync，不等于 GPU 耗时；引擎内存值是进程计数，不能当作某张地图独占显存。单次自动路线是下一轮定位瓶颈的线索，不是跨设备性能承诺。未测试实体手机。
