# 可选体感辅助瞄准

2026-11-06。菜单／暂停界面的“体感瞄准”打开独立面板，默认关闭。

- 开启后才请求 DeviceMotion 权限并订阅传感器；敏感读数仅在内存消费，不上传。缺少接口、不安全上下文、拒绝授权或 3 秒没有有效读数，均保留正常触屏玩法。
- 灵敏度 `0.25x–3.00x`，默认 `1.00x`，独立于触屏灵敏度；只保存此数值，不保存开启状态。提供重新校准按钮。第一次启用自动校准，需要约 650ms 连续稳定采样，移动过多时提示重新校准。
- 角速度积分成弧度，按传感器实际采样间隔处理，加入零偏校准、小死区、低通滤波、速率与积累上限。每个物理帧消费一次，不重复积分。
- beta／gamma／alpha 分别是设备 X／Y／Z。屏幕方向修正俯仰轴；有合理的含重力加速度读数时，把角速度投影到竖直轴，兼容倾斜持握；否则使用屏幕 Y。W3C 的面朝上静止示例是 Z=+9.8，不将其误当向下的重力向量。[W3C](https://www.w3.org/TR/orientation-event/)
- 暂停、失焦、后台、竖屏、重生、状态切换和过长采样间隔清除增量。手机旋转后不带入旧读数。与触屏瞄准相加，仍使用原游戏俯仰限制。
- 游戏中不显示设置面板或提示。面板支持键盘焦点约束、Escape、点击背景关闭，横屏窄高度可滚动。
- 加载界面移除了简历／作品集跳转链接。

## 验证

- `node tests/gyro_test.mjs`：权限允许／拒绝／异常、取消等待授权、没有传感器数据、校准／重新校准、两侧横屏、倾斜持握、灵敏度比例、读取一次、空值、事件频率与生命周期。
- `node tests/mobile_input_test.mjs`：既有触屏／全屏提示回归，以及真实体感模块进入输入包、暂停与重生门控。
- Godot rules、导入和 Web 导出／资源清单检查通过。
- 加载测试要求渲染帧，首次无头运行不适用；已改用实际渲染运行并通过 `LOADING_CHECK_PASS`，未把无头失败算作通过。
- Chrome 本地 844×390 检查设置、灵敏度、无传感器回退、开局、开火、暂停；390×844 检查竖屏保护；刷新保留灵敏度，体感回到关闭。未见控制台 error。

这是可供真机试玩的第一版体感控制。自动化验证不能证明 iPhone／Android 的实际传感器方向、漂移、延迟或手感；仍需在两类手机上实际体验。默认可关闭，不影响原触屏方式。

接口依据：[角速度](https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent/rotationRate)、[主动授权](https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent/requestPermission_static)。
