# 逐颗推弹音效

加载进度装弹和游戏内换弹共用一段 32 毫秒的短促金属咔嗒声，音量为 -12 dB。每颗子弹完全推入时播放一次，直接跟随现有动画的整颗子弹边界。游戏内保留换弹开始的机械声，总换弹时间仍为 0.9 秒。

空弹夹补 20 发、剩 14 发补 6 发、剩 19 发补 1 发，各自只播放对应次数。加载等待停在 17 发时停止发声，准备完成才补最后 3 发。暂停、焦点挂起、死亡、加载取消或重新开始不会留下独立的装弹音效计时器；弹夹下沉、回位和缩入 HUD 期间不重复播放推弹声。

音源为原创程序合成，生成脚本在 `tools/build_audio.py`，游戏素材在 `assets/audio/cartridge_insert.wav`。

验证通过：

- Godot 4.7.2 导入和计分规则检查。
- `--qa --reload-audio`：检查实际音频播放节点，覆盖 20/6/1 发、暂停、延迟帧完成、死亡、截止时刻、重开，以及加载 17+3 发、挂起、取消和再次加载。
- 真实渲染的 `--qa --loading` 和 `--qa --magazine`：核对推入子弹数与音效次数，保留装弹像素计数、54 个物理帧完成和小窗口检查。
- 游戏音频总线录下 0.949 秒换弹声音，确认输出非静音且无削波。录音保留在 Git 忽略的 `artifacts/local/cartridge-reload.wav`。

以上为自动检查和引擎渲染、录音验证，未进行人工听感或手感验收。
