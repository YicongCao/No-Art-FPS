# 玩具机甲爆头击杀反馈设计

状态：设计方案，尚未实现。适用 `toy` 分支当前机甲敌人；沿用现有判定、伤害、计分和60秒对局规则。

## 目标与现状

玩家在命中后约0.1秒内能分辨“爆头击杀”和“身体命中”，15–25米处仍有清晰确认。爆头的视觉奖励应强于当前身体中弹的碎片反馈，同时让准星附近尽快恢复清晰。

当前代码：

- `scripts/enemy.gd` 的 `take_damage()` 只在非致死伤害后调用 `apply_nonlethal_hit()`。因此一枪爆头不会触发护甲碎片、部件崩落与持续战损。
- `scripts/game.gd` 的 `resolve_shot()` 给头部命中生成的火花参数为 `.07 / .12`，身体为 `.12 / .16`；头部现有世界空间效果更小。
- `on_kill()` 已有爆头专属音效，但准星与计数反馈仍复用普通击杀状态。
- 死亡动画目前立即侧倒、下沉，约1.4秒清理；没有头部受击动作。

## 核心表现：头甲崩开，核心闪灭

爆头呈现为头部装甲被打穿并发生一次短促机械过载。白金亮点是全兵种共同识别信号，飞散碎片继承各自装甲颜色。视觉重心始终落在命中的头部。

以下数值为首版调参起点，需要实机验收后确定。

|阶段|时间|玩家看到的效果|
|---|---|---|
|命中确认|0–60毫秒|弹着点出现白芯、金边的四向星芒，带少量暗色外缘以适应亮天；第一帧最亮，迅速收掉白芯。|
|装甲崩开|20–180毫秒|2–3块较大的头盔/面罩壳片朝弹道方向及两侧弹开，另有4–6个小碎屑；大碎片负责轮廓，小碎片补动势。|
|核心熄灭|40–220毫秒|面罩亮起一次，露出的深色机械内核短闪后熄灭；最多两根短电弧向内收缩。仍能读出机械头部结构。|
|死亡动作|0–350毫秒|头部先沿受击方向甩动、上身短促后仰，约60–90毫秒后接现有侧倒；击杀、碰撞关闭和计分在命中时立即生效。|
|收尾|180–650毫秒|小火花先消失，大壳片沿脚本抛物线下落并缩小淡出；尸体沿用现有清理时限。|

### 两种敌人的区别

- **步枪兵**：红色冠脊与深色头盔外壳断开，面罩裂成两片，露出深灰机械头芯。碎片较厚，动作偏沉重。
- **突击兵**：橙色前盔与一侧尾鳍崩飞，面罩向侧上方甩出，露出短促青色电弧。碎片较薄，动作更利落。

不需要现场切割完整模型。建模时准备少量低面数头甲碎块与头芯；运行时切换可见件并发射独立碎片。已发生身体战损的敌人仍可触发此效果，但不会恢复或重复弹出已经脱落的装甲。

## 准星与声音

爆头使用独立于普通击杀的约0.22秒准星确认：四个白金双色短刻度向中心快速收拢，再轻微回弹淡出，中间留空。1080p参考外径约22–28像素，随HUD缩放；深色细底线保证在天空和浅墙前可读。使用绘制线段，不增加文字、图标字体或常驻标签。

正常击杀继续使用现有金色命中标记和计数变化；爆头确认优先显示。连续爆头刷新短动画，最多一次温和回弹，不叠加成满屏图案。计数和已有连杀反馈继续沿用原逻辑。

沿用已有爆头音效，按需要补一声短促塑料破裂/机械断电质感。音频优先级应避免同一枪的普通命中声、击杀声和新碎裂声同时堆叠。

## 可读性与性能边界

- 星芒以头部局部范围为主，初始世界尺寸约0.35–0.50米；近距离限制屏幕覆盖面积。远处主要依靠亮暗形状和准星确认，不无限放大世界粒子。
- 闪光和电弧接受场景深度遮挡，保留遮挡物关系；不透墙显示，也不增加全屏泛白。
- 视觉停顿仅作用于被击杀角色的姿态，游戏时钟、输入、开火和敌人AI持续运行。默认不增加镜头抖动或FOV变化。
- 碎片使用脚本轨迹与共享网格/材质；复用现有 `CombatFX` 的批量实例思路，关闭碎片投影，不创建独立刚体或实时灯。
- 首版预算目标：单次效果3–4个绘制批次，约10个可见碎块/火花，主要效果650毫秒内回收；同时最多6组完整效果。超额时保留命中闪点与准星确认，缩减碎片。
- 减少动态效果模式保留准星确认、低亮度短闪和2–3块慢速碎片，省去电弧、强烈甩头与回弹。
- 枪口和第一人称武器的表现不变，避免击杀反馈影响接下来一枪的瞄准。

## 接入方式

1. 在射击命中处记录弹着点、法线和入射方向，向伤害/击杀流程传递命中上下文；终局处决、火焰持续伤害和爆炸保留各自来源标识。
2. 由成功登记的爆头击杀统一触发专属世界效果与HUD确认，保证每名敌人只触发一次。替换当前微小头部火花，避免同一命中重复生成两套闪光。
3. 在敌人视觉层保存头部部件与死亡姿态信息，按敌人类型播放头甲崩开动作。碎片挂在独立效果容器中，能在敌人清理后完成收尾。
4. 在 `hud.gd` 增加独立爆头确认计时与绘制，不借用 `kill_pop` 反推击杀类型。暂停、重开和结果页切换清理状态。
5. 搞笑模式保留现有替代头部，首版只叠加通用命中星芒与爆头准星，不弹出不属于该模式的机甲头盔；狂暴子弹爆头仍使用同一确认，并限制与火焰的亮度叠加。

## 验收

- 两个兵种分别验证：满血爆头、身体受伤后爆头、连续命中尸体、普通身体击杀、狂暴身体一枪击杀、爆炸与终局处决。只有真正的爆头击杀生成专属效果，计分与伤害结果不变。
- 固定机位记录命中前、约33/100/220毫秒和650毫秒状态，并录制正常速度短片；静帧不能代替动画节奏验收。
- 在货场亮天、办公室室内和雨市高反光背景，以近景、15米和25米测试。静音仍可分辨爆头，且能立即瞄准下一名敌人。
- 检查降低动态效果、瞄准镜内、屏幕边缘击杀、暂停恢复、重开、模式切换和已受损敌人的零件状态。
- 分别采样单次爆头和多次连续爆头，比较首次触发与预热后的帧时间、P95/P99、最大帧及绘制批次。若首次有尖峰，将网格、材质与效果实例准备移至现有加载阶段。

建议先完成“星芒 + 大头甲碎块 + 独立准星确认”作为可玩样板，再加入头芯、电弧与动作细化；每一步以正常战斗距离下的辨识度判断效果。
