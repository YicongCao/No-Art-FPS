# 九张地图可破坏物扩充建议

2026-11-13。基线 9e5b798。本轮为设计清单，尚未改动游戏或发布。

## 先解决玩家能否感知破坏

现有脚本中，普通结构只有狂暴射击才调用 ignite_hit，且需两次命中才引燃。办公室木门存在普通射击两次破门的特殊处理，爆炸桶也能在普通模式引爆。场景宣告的破坏根节点很多，但并不等于每个小物件都能独立破坏。

静态场景声明统计：沙城 15、游乐园 72、渡轮 12、摄影棚 83、办公室 101、城堡 18、雪线天文台 14、棕榈屋 23、银座站 16 个结构／道具破坏根节点，另各有 3–7 个爆炸桶。统计包含整组建筑、桌组和设备，不代表经过实机确认的独立可射击目标数量。原始节点清单见 current-scene-inventory.json。

所以扩充应同时做两件事：增加贴近玩家的小目标；把已有大目标拆出可识别的局部破坏。以下“新增”是新物体，“拆分”是现有物件新增独立破坏部件。数量为候选，不建议一次全堆进地图。

## 模式与反馈建议

- 普通模式：小物件 1–2 枪破坏；中型对象先损坏、再破坏。让前半局就能玩到。
- 狂暴模式：缩短破坏过程，并允许少数明确的关联对象连续破坏；保留大型结构的狂暴专属身份。
- 小物件主要提供材质反馈；只有明确标识的机关才影响敌人。陶罐、纸张、花盆不统一触发伤害爆炸。
- 对象有完整、受损、破坏后的可读状态；优先保留底座／空架／碎口，避免整组瞬间蒸发。
- 计分仍以击杀为核心，先不加刷杂物分或补给掉落；机关辅助击杀按现有击杀规则结算，后续单独验证。

## 数量、摆放和第一轮优先级

每图先选前三项，共 27 类。每项做 2–3 个放置组，暂定每图 6–9 个新增或升级的可互动组；这只是首轮采样量，最终按地图空间与实测调整。一个架上的一组小物不等于给每个碎片分配逻辑对象。

每个主要交战区，从常见行进方向能看到至少一个明显可破坏目标。将它们放在墙边、摊台和设备侧，形成用途组合；不要均匀撒满地面。避免新增对象遮住敌人头肩，或挡住既有出生点、坡道和门。

第一轮先做沙城陶罐／果筐、办公室局部屏幕／手办、游乐园气球／叠罐。用三张地图验证硬质碎裂、局部设备损坏、轻物弹开三种差异，再复用组件到其余地图。机关型破坏后做，须有预警、范围、敌人受击与路线验证。

## 实现与验收约束

1. 新增独立的普通道具命中入口和破坏类型；不能直接把全部现有结构的狂暴限制移除，否则会过早拆掉掩体、道路和大型演出。
2. 普通小物破坏无需调用现有 scenery_blast；目前它在狂暴状态会伤害敌人，若每个杯子都复用会变成满图爆炸。明确区分纯反馈、移除局部遮挡、预警机关三种行为。
3. 优先完整模型／受损模型切换，加少量预制碎块。轻物轨迹采用动画或已有 CombatFX；避免大量 RigidBody3D、实时绳索和布料。
4. 保留一小块无碰撞残骸或底座；短寿命飞散碎片使用数量上限。喷水、雾、纸片和闪光分别设置上限，并服从 reduced_motion。
5. 按地图与破坏类型决定声音，不给所有物件加爆炸声。玻璃、陶器、木料、金属、纸张和软物形成差别。
6. 对没有通行影响的小件避免触发导航重烘焙。移除实际障碍、改变射线或产生伤害的物件必须单独验证，不能仅凭视觉标记 scenery=true 就假定安全。
7. 重开完整恢复物体、碰撞、局部灯和动画状态；狂暴切换时不瞬间集中生成大量碎片或预计算所有破坏状态。
8. 在 Web 比较空闲与连打密集道具的长帧、碎片数量和透明覆盖。测试普通／狂暴、手雷波及、重复命中、暂停重开与连锁上限。

## 当前代码依据

- scripts/game.gd 的 shot_collision_mask、resolve_shot：普通／狂暴射线目标与破坏命中分派。
- scripts/destructible.gd 的 ignite_hit、collapse：狂暴条件、两次命中、整组隐藏、碰撞移除与导航更新。
- scripts/maps/office_door.gd：普通木门特殊破坏。
- scripts/explosive_barrel.gd：普通命中引信与狂暴爆炸。
- scripts/maps/bb_office.gd、concept_arena.gd：已有键帽、水滴、木片、园艺、玻璃等材质命中反馈。新增时应扩展状态而非只重复粒子。

以上建议没有新增模型、修改碰撞或调整模式规则，实施范围仍待确定。
