# 爆头击杀反馈首版

2026-11-13，`toy` 分支可玩样板。沿用伤害、命中判定、计分和 60 秒时钟；只改变确认反馈与死亡表现。依据 [设计方案](../../../design/toy-headshot-kill-feedback.md)。

[正常速度实机短片](headshot-demo.mp4) · [分帧对比](comparison.html)

## 实际表现

- 弹着点出现深色外缘、金边白芯的短星芒，110 ms 内缩掉。接受深度遮挡，不增加全屏泛白。
- 隐藏头盔与面罩，露出原有机械头部；核心短闪在 220 ms 内熄灭。
- 每次生成 3 块大壳片、6 块小碎屑和 3 点火花。步枪兵用深蓝、红、乳白，突击兵用橙、乳白、青色，后者壳片更薄。
- 命中方向驱动短促上身反应，约 75 ms 后衔接现有侧倒；碰撞与计分立即结算。
- 独立的白金准星确认持续 220 ms，中心留空；连续爆头刷新而不堆叠。沿用爆头音效，移除同一枪重复的普通命中声。
- 650 ms 回收碎片，尸体仍按原有 1.4 秒清理。暂停冻结动画，重开清理效果。

本轮不是逐面拆解原头盔：使用程序生成的共享倒角壳片，按兵种调整颜色和比例；保留原机械头部。原设计中的专用裂片、独立头部关节动画、青色电弧及新增音效尚未加入。先用这版判断正常速度下的辨识度和力度。

## 开销与降级

壳片和火花复用 `CombatFX` 的 MultiMesh 批处理；共享网格与材质，不创建刚体或实时灯，关闭特效投影。加载阶段预热。完整世界效果最多 6 组，超额保留短闪和准星；单组最多 3 个绘制批次，敌人核心额外 1 个。减少动态效果模式保留 3 块慢速碎片、较小闪光，取消火花和准星回弹。搞笑头部只使用通用短闪与准星，保留原模式效果；马桶大爆炸继续优先。

Apple M5，Godot 4.7.2 Compatibility，1440 × 810，VSync 开启，每段 8 秒；固定货场机位，停用 AI，只隔离测量新特效，不包含连续生成敌人、尸体或完整战斗。预热已开启。

| 场景 | 帧间隔 P50 | P95 | P99 | 最大帧 | draw calls P95 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 无特效，前置基线 | 10.04 ms | 15.84 ms | 22.03 ms | 23.83 ms | 1490 |
| 每秒 1 次 | 10.46 ms | 21.37 ms | 22.81 ms | 23.38 ms | 1493 |
| 每秒 10 次 | 10.60 ms | 21.55 ms | 22.26 ms | 23.59 ms | 1500 |
| 无特效，后置基线 | 10.12 ms | 16.93 ms | 22.27 ms | 22.78 ms | 1490 |

10 次/秒时完整效果峰值为 6 组，构建 CPU 时间 P95 为 0.159 ms。首次玩法触发的构建耗时为 0.150 ms；这是预热后的测量，不是冷 shader 编译测量。帧间隔包含 VSync 和系统调度，不能当作纯 GPU 时间；P95 有上升，这段短测没有超过基线最大值的尖峰，也不能由此保证所有地图或 Web 上无卡顿。参见 [原始数据](performance.json) 和 [采样日志](data/performance.log)。

## 验证

- Godot 全工程导入、规则测试通过。
- 新 `headshot_check.gd` 使用真实 `game.shoot()` 验证两兵种满血/受伤后爆头、单次计分与碰撞关闭、暂停、效果回收；覆盖尸体重复命中、身体与狂暴身体击杀、爆炸、终局处决、搞笑模式、减少动态效果、6 组上限和重开清理。
- 现有 `--combat` 通过，包括两兵种身体战损、爆桶、刀兵和暂停；`--damage-feedback` 通过，包括方向提示、音频、预警和死亡视角。
- 1440 × 810 原生分帧：两兵种命中前、身体命中、爆头后 33/100/220/650 ms，以及 15/25 米。静帧脚本直接调用同一伤害事件以锁定姿态，不能单凭它证明射线判定。
- 1280 × 720、60 fps 正常速度短片使用真实射击；顺序为步枪兵身体、步枪兵爆头、突击兵身体、突击兵爆头。录制固定时钟，不能作为性能测试。
- 已检查实机分帧与短片抽帧；不是人工完整试玩。尚未逐图验证室内、高反光场景、瞄准镜与屏幕边缘的视觉效果。本分支不做 Web 发布。

检查日志保存在 [data](data/)。录像与截图为本项目实机输出，不是概念图。

## 复现

从项目根目录运行：

```sh
python3 tools/qa_run.py --headless --editor --import
python3 tools/qa_run.py --headless --script tests/rules_test.gd
python3 tools/qa_run.py --script tests/headshot_check.gd
python3 tools/qa_run.py --fixed-fps 60 -- --qa --combat
python3 tools/qa_run.py --fixed-fps 60 -- --qa --damage-feedback
python3 tools/qa_run.py --script tests/headshot_capture.gd
python3 tools/qa_run.py --script tests/headshot_performance.gd
```

正常速度录制使用 `tests/headshot_capture.gd -- movie`，配合 Godot `--fixed-fps 60 --write-movie <绝对路径>.avi`。根据日志 `HEADSHOT_MOVIE_START/END` 帧号裁掉启动画面，再编码 H.264/AAC。不要与性能采样同时运行。

试玩：在 `toy` 分支执行 `godot --path .`，进入任意地图瞄准两类机甲头部开枪。
