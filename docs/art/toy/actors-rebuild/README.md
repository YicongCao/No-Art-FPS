# 敌人主体曲面重建

用户反馈上一版整体差异太小。本轮重做主体，沿用 gameplay 节点、枢轴、碰撞和攻击逻辑。仅 toy 客户端，不发布 Web。

[同机位前后对比](comparison.html)

- 步枪兵：用多截面曲面替换方盒躯干与头盔，加宽胸肩、收紧腰部；重建弧形大腿、小腿和靴子，扩大面罩，重排抱枪手臂并加长枪身。肩甲改为曲面体。
- 突击兵：头盔改为连续后掠曲面，不再是三角厚板；躯干呈肩宽腰细的收束轮廓；四肢有独立深色关节、流线护甲和弧面靴子。
- 建模脚本新增多截面 loft 与曲面体构造，保留可编辑 Blender 源文件。当前仍是风格化程序模型，不声称达到概念图的完整精细度。

|角色|三角面 前→后|网格数 前→后|
|---|---:|---:|
|步枪兵|9088 → 11012|29 → 32|
|突击兵|8352 → 10548|23 → 24|

新增曲面有几何成本，本轮未做帧时间对比，不声称性能无变化。近景、约15米和25米截图均重新采集。

验证：Godot 导入、规则测试、原生战斗（冲刺、挥刀、攻击打断）、30%命中率、伤害反馈与死亡视角检查通过。本轮为自动化验证，未进行人工手感验收。
