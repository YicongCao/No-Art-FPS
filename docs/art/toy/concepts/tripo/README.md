# Tripo 试点素材

2026-11-11，内置图像生成工具产出，作为 Tripo 多视图生成的输入，不是最终尺寸图。和方向概念图相比做了简化：去掉小部件、通风口和发光效果，发光部位一律画成纯色，白底、平光、无投影、正交视角。

每个目录里，`sheet.png` 是原始拼版，单视图都已裁成 1024 x 1024 的白底方图。

## 角色（T 字姿势）

| 目录 | 对应 | 视图 |
| --- | --- | --- |
| `rifleman/` | 黑色远程敌人 | `front` `left` `back` `right` |
| `rusher/` | 橙色持刀敌人 | `front` `left` `back` `right` |

角色手里不拿武器，武器单独建模后挂到手部节点上。

## 武器

武器不存在 T 字姿势，所以按道具出四视图：`left`、`right` 两个侧视，`top` 顶视，`front` 是正对枪口的端视，没有后视。

| 目录 | 对应 |
| --- | --- |
| `enemy-blaster/` | 步枪手的武器 |
| `rusher-blade/` | 突击手的刀刃 |
| `player-rifle/` | 常规模式的玩家枪 |
| `water-blaster/` | 大便模式的滋水枪 |
| `mop-launcher/` | 蟑螂模式的拖把枪 |

当前代码里，蟑螂模式用的是发射拖鞋的 `slipper_launcher.glb`，所以拖把枪的杆上保留了一只拖鞋，开火逻辑和弹体都不用改。

## 上传建议

- **角色：** 用多视图模式，依次放入前、左、后、右四张图。
- **武器：**
  - 多视图模式下，前视位放 `front`，左右两位放 `left` 和 `right`，后视位留空；
  - 结果不稳时，改用单张 `left` 侧视图生成。
- **导出设置：** 选低模或 Smart Mesh，三角面上限 8000 到 15000，导出 GLB。只用几何，颜色在项目里按色板重新上。

## 已知的视图偏差

- **`rusher-blade/front`：** 刀身比侧视图短，以侧视图长度为准。
- **`mop-launcher/front`：** 拖布头偏低，以侧视图里拖布头位置居中为准。
- **`water-blaster/top`：** 顶视多画了一个水窗，可以忽略。
