## 统一验收

- 使用当前敌人版本重新拍摄基线，同地图同机位、FOV、光照和色彩；普通战斗距离下应看得出主形体或深度变化。
- 分开记录不带顶点烘焙的几何对照和最终烘焙效果。
- 保存可编辑 Blender 源件、生成器和游戏导出；记录面数、材质 surface 数及烘焙细分。
- 核对布局数据，检查对应地图导航、射击、破坏和重开；实机截图与自动路线检查不冒充人工试玩。
- 同机独立运行性能采样，普通、狂暴及切换各至少三次，记录 P95/P99 和长帧。固定起点缓慢转头是受控负载，不代表全图最坏情况。
- 货场复核后，实际切换验收采用自然跨过第45秒的采样；直接跳时钟的结果单列诊断，它还会改变补兵和敌人状态。测量工具支持 `--phases normal frenzy natural-transition`。
