# 办公室成型家具样板

2026-11-13，toy 分支，基线 `b33a237`。本轮围绕已有高频工位与公共设备重做主体几何。

[实机前后对照](comparison.html)包括战斗距离、工位近景、屏风侧面、打印机和饮水机五组固定机位，1440 × 810、FOV 63°。未改变光照、色板、曝光、墙面海报或材质参数。家具属于可破坏资源，不参与静态顶点烘焙；本轮保留原有静态资源，因此几何版与最终版相同，没有借重烘焙改善画面。

## 实现与边界

- 椅子：连续弯曲的椅背，腰部收窄、肩部展开，橙色顶部和后部支撑独立成型；增加真实轮子。改动复用到工位、访客椅和会议桌组合。
- 工位：实心板式桌腿替换为开放支架，桌面与支架有接合关系；显示器改用连续收分后壳和带凹入玻璃的圆角前框。
- 屏风：低屏风去掉密集方柱，改为带圆肩、连续顶边与嵌套软垫的整块成型壳体；高屏风和储物端柜保留原有通视范围和占地，改造面板转角与壳体。
- 公共设备：打印机扫描上盖、侧壁和背桥围出真实出纸槽；饮水机侧颊围出接水腔，水龙头在内腔中。孔洞均有背板，不呈现可穿透整台设备的假象。
- 沿用已有材质，按材质合并导出；没有新增贴图或逐家具灯。可编辑源为 `art_source/bb_office.blend`，生成器为 `tools/build_bb_office.py`。
- 保留天花管线，未将其密度清理与家具样板混在一起。低收益天花细件仍是后续性能优化候选，本阶段不声称完成了办公室全资产重建。

布局 JSON 与基线逐字节一致，见 [布局指纹](data/layout-proof.json)。地图场景文件也未改动；碰撞、导航、物件枢轴、破坏生命周期和出生点沿用原场景。所有未改造的GLB均恢复原版本，尤其保留已烘焙的建筑、管线与房间资源。

## 性能

Apple M5，Godot 4.7.2 Compatibility，1280 × 720、VSync开启。普通、狂暴稳态、自然第45秒切换前后各三轮，每轮8秒；固定起点、活跃敌人AI与缓慢转头。自然切换从第42秒开始采样，不跳过时钟。采样期间没有运行Blender或其他游戏检查。

中途跨会话后，旧版基线曾为约52毫秒，新版却约12毫秒。重新加载旧家具后也恢复到约12毫秒，说明原始基线受运行环境影响，不能计作建模优化。下面采用当前会话先测新版、再恢复旧版复测的18个样本；早先9个样本保存在 [排除的跨会话基线](data/performance-prior-session.json)。没有将顺序测量包装成随机交替实验。

## 复现

```sh
blender --background --python-exit-code 1 --python tools/build_bb_office.py
godot --headless --path . --editor --import
godot --path . --script tools/maps/capture_scene_evolution.gd -- bb_office after
python3 tools/qa_run.py --script tests/bb_office_check.gd
python3 tools/qa_run.py --headless --script tests/map_scene_test.gd
python3 tools/qa_run.py --headless --script tests/rules_test.gd
python3 tools/maps/measure_scene_evolution.py bb_office after --phases normal frenzy natural-transition
```

生成器会导出整套办公室资源。复现本阶段时保留上述12个家具GLB，其余静态和未改造资源恢复基线，避免覆盖现有烘焙；若选择重建整套，需另行重烘焙并重新验证。
