# 游乐园曲面顶棚与售票亭

2026-11-13，toy 分支，基线 `b7a299c`。[实机前后对照](comparison.html)包含出生点战斗距离、木马近景、顶棚侧面与售票亭四组固定机位，1440 × 810、FOV 63°。

## 实现

- 旋转木马：16条红白色带沿弯曲的放射截面展开，坡度从中心到边檐逐渐减小；每条色带沿径向12段、角向4段，带10厘米厚度。相邻色带的边界位置相同，不生成夹在条带之间的内部侧壁。
- 金色支肋沿新棚面弯曲，蓝金边檐从五边形折线改为连续圆弧垂边。保留原有顶点冠饰、灯泡数量、主柱、围栏、转盘、马匹与动画节点。
- 两侧售票亭使用连续成型壳体、完整墙厚、嵌入式窗框和深色背板。窗口从檐口下凹入约60厘米，面向园内的一面也有窗口；每侧窗口均由背板封闭，不制造贯穿亭体的洞。蓝色顶盖和金色压边改为连续收分截面。
- 沿用原红白棚布、蓝金边檐、青绿色亭体，材质参数、夕阳、天空、曝光和全图光照均不变。没有增加贴图、灯光或材质surface。

本阶段只替换 `carousel_roof.glb` 和 `entry.glb`，可编辑源为 `art_source/amusement_park.blend`，生成器为 `tools/build_amusement_park.py`。这两个资源均归属可破坏组件，未参与静态顶点烘焙；静态地面、建筑和其余资源恢复基线，几何对照即最终版本，无额外重烘焙。

## 复现

```sh
blender --background --python-exit-code 1 --python tools/build_amusement_park.py
godot --headless --path . --editor --import
godot --path . --script tools/maps/capture_scene_evolution.gd -- amusement_park after
python3 tools/qa_run.py --script tests/amusement_park_check.gd -- --park
godot --headless --path . --script tests/map_scene_test.gd
godot --headless --path . --script tests/rules_test.gd
python3 tools/maps/measure_scene_evolution.py amusement_park after --phases normal frenzy natural-transition
```

构建器导出全套资源。复现本阶段时只保留 `entry.glb` 和 `carousel_roof.glb`，其余GLB恢复基线；不要用未经重烘焙的完整原始导出覆盖现有静态光照资源。
