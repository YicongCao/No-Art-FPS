补齐概念图缺项，统一近景观感

本轮重点补上 C 阶段缺少的地表细节、设施表面层次、外窗、接触阴影、近景岩石、第一人称装备、字体和音色。保留已批准的飞船与机甲、现有路线和一分钟规则；基地室内继续关闭。没有新增 Tripo 付费任务。

主要物件与视觉系统已接入，不等于概念图写实程度或整份策划案验收全部完成。下方逐项区分实装、自动检查、人工验收和延期事项；性能优化与生产发布仍未在本轮执行。

同机位：左 C，右 D

本轮补齐的内容

  • 月壤细颗粒与法线、平滑远山法线、4 种近景岩石和 20 处岩块布置；近处碰撞经导航检查。
  • 设施、货箱、枪械的磨损/粗糙度/法线共享分布，离线烘焙为纹理；保持原有主色，不加全屏灰雾。
  • 三块深色镀膜外窗，4 处静态接触阴影；不制作基地室内，不新增平面反射渲染。
  • 缩小瞄具、打开能量线圈、降低持枪白漆和补光强度；新增装甲手雷与投掷手套，物理和库存规则不变。
  • 三盏预建局部过载灯与线圈橙色状态，退出后恢复青色；不全图洗红。
  • Oxanium + Noto Sans SC 子集与许可、简化数字 HUD、数字弹量和 SVG 手雷图标；独立开始界面与 Web 加载字样。
  • 原创离子射击、装填、预警、脚步、金属、爆炸和 60 秒音乐，45 秒提高音乐密度；无下载音频素材。

Godot 导入、导航和实际坡道行走、规则回归、机甲状态与爆头、ADS、弹匣动作、新手雷单次释放/暂停/重开均已自动检查；8 组 20 个破坏目标保留真实射线命中证据。新增岩块曾占用 Spawn4，已移位后重新通过导航。手雷 SVG 首次绘制的临时纹理生命周期导致白块，改为持久缓存并截图复验。

与概念图仍然不同的部分

实机仍是偏低模的 Web 样片：岩层造型、设施接缝/软管密度、机甲脚部贴地、手部握持、枪械近景细节和玻璃反射层次尚不等同写实概念图。当前玻璃是封闭外窗；行星是程序化风格化背景，不是真实地球地理纹理。没有通过水面、浓雾、过量 Bloom 掩盖这些差距，也未把它们标成已经完成。

下一轮优先保留当前效果做性能优化；随后可针对近景材质、动作与人工游玩反馈收敛。本轮不追加室内、不改变 60 秒玩法、不合并主线或覆盖生产站。复现与来源 · 检查摘要 · 新装备状态检查
