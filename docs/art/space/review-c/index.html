起点、朝向和分辨率一致；动态敌人帧可能不同。主基地和英雄资产沿用已批准方向。本轮新资产全部程序化制作，没有新增 Tripo 消费。

地编与主要替换

货箱新增护角、锁扣、嵌板、搬运孔和标识；平台与坡道增加板缝、防滑条。地面增加细碎岩石。远景天体使用球面程序纹理，只作风格化视觉，不是准确的地球地理图。山体在边界外，室内继续关闭。

可破坏物：四种反馈，八组布置

类型组 / 目标行为
电池架2 / 6单发击破，剩余电池延迟连锁放电；留下残件。
压力阀门2 / 6单发击破，短促喷泄与金属碎屑。
控制台2 / 4普通弹两发、狂暴弹一发；屏幕熄灭，产生电火花。
补给箱2 / 4普通弹两发破坏独立舱板，显示暗色残腔。

破坏不增加击杀分数、不额外修改敌人伤害，也没有把工业设施都设为伤害爆炸桶。静态掩体和主要通路保留，小道具沿用原有射击目标层。目标破坏后关闭命中碰撞，重开复原；电池连锁在暂停时冻结。

验证结果

  • 8 组 20 目标的射线命中、两发耐久、残件显示、碰撞关闭、电池连锁、暂停冻结、范围破坏和重开复原通过。
  • 导航标记可达，真实角色可以走上原服务坡道；完整 60 秒、45 秒狂暴、结算重开与会话隔离通过。
  • 原九张地图的交互物回归通过：普通/狂暴命中、手雷遮挡、复原和导航保持不变。
  • Chrome 完整回合持续射击、换弹、结算、重开、暂停通过；844 × 390 触控模拟通过，未记录脚本错误。
